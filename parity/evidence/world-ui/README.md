# 世界设备与便携界面核对

本组为 11 个世界设备、工具箱、核容器、作物分析仪和两种高级搬运升级接入原生菜单。各入口、界面状态、贴图 SHA-256、原生窗口尺寸和背包/分页坐标见 [`spec/gui/world-portable-panels.json`](../../../spec/gui/world-portable-panels.json)。作者包中没有独立地形改造机面板，该机使用作者 `common.png` 构造面板。矿物扫描仪和 EU 测量仪由各自负责人另行验收。

分拣机和加权分配器对原有完整库存采用分页；切换页面只激活对应实槽。Shift 转移显式检查目标槽是否激活、是否允许物品，避免合并到隐藏槽。区块加载器面板可选择相对区块和启停；矿机、先进矿机的状态按钮接已有服务端行为。工具箱及核容器绑定真实持有物并保存内容。作物分析仪提供种子输入、分析输出和供电槽，关闭时退还临时物品，保留原来的副手种子快捷分析。

高级弹出与高级拉取升级的普通空中右击打开公共面板。九个全息样本槽不消耗手中物品；允许/排除、物品耐久和电量匹配、输出方向保存在升级物品上，仍支持原有副手取样与潜行选面。旧单样本配置可以读取。几何依据为对照包公开的 `assets/ic2/guidef/advanced_upgrade.xml` 和作者重绘图集；未读取原版生产源码。

三份 `neo-*-worldProgram.properties` 是独立临时世界加载实际打包 JAR 的原生服务端结果，JAR 名称和 SHA-256 见 [`neo-jars.json`](neo-jars.json)。NeoForge 1.21.1、26.1.2 和 26.2 各运行 320 游戏刻，每版 74 项断言通过。与本组直接相关的 10 项覆盖分拣机/分配器分页及 Shift 转移、九个高级升级样本保存与不消耗、允许/排除、耐久与电量比较、重开后方向和样本，以及机器侧的高级拉取实用链。

Forge 1.19.2 对应 Java 菜单已编译通过；本组尚无最新 Forge 服务端行为报告。以上结果是服务端和菜单行为证据，不是最终客户端视觉验收：三版 Neo 与 Forge 的实际画面、槽位点击、便携物重开及分析仪退还由并行客户端探针另行提供。最终格式化、打包和重测后，应重新记录最终 JAR 的校验值。
