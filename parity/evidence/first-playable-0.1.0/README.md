## 从修复版到四个终包

Forge 的 22 项 GameTest 在同一源码提交的 ForgeGradle 开发运行时执行。另用重混淆 JAR 分别安装客户端和专服，验证十组游玩场景、37 次实际合成与 1,024 种管道几何组合。三版 NeoForge 的专服与 JAR 字节比对后载入，图形探针另行加载，逐条核验实际运行的生产类和资源。

- 用原修复版专服与真实客户端采集 104 个菜单入口，其中 96 个可直接打开。原版 GUI 验收 104 项、工作台专项 22 项通过。另记录了 1.2.4 参考服的加工、缺料、满输出和核堆读数。[原作界面和工作台](reference-ui.json) · [参考服逐刻快照](../reference-1.2.4/README.md)
- 四版均与参考注册表的 292 种方块和 552 种物品逐项对应，另有泡沫喷枪。获取路径核对使用实际注册表、战利品实测、自然生成、加工规则和配方依赖。调试物品和创造模式物品单列。[获取路径总表](acquisition.tsv) · [四版注册摘要](registry.json)
- 77 张作者 GUI PNG 在每个 JAR 中均与回交包逐字节相同。客户端还核验了实际菜单、槽位边界、物品拾取和放回、模式切换及液体状态。部分机器使用作者专用整图，其他机器按公开布局组合 common.png 的边框、槽格和图标。[素材校验](artwork.json) · [工作台实机对照](workbench-comparison.png) · [成形与洗矿实机对照](processing-comparison.png)
- 洗矿按每次 1,000 mB 水结算，高炉测试从冷态运行到产出钢和炉渣，满输出时保留原料。核堆覆盖单棒输出、扩展仓、冷却回路六周期读数和跨进程状态恢复。[世界、农业与升级](../world-program/README.md) · [玩家装备](../portable-equipment/README.md)
- 经典与实验机型配方重叠时，本版用可逆选择配方保留两条路线。少数参考版孤立材料具备补充生存配方，分别列入玩家指南。存档验收覆盖 0.1.0 自身的新世界、存档和重开。修复版与重建版共用 ic2 命名空间，两个版本分别使用独立存档。
- 源码相似度的原始数据和人工裁决均保留。对高分框架适配、重复导入和实际方法体分别核对，使用冻结提交的实际编译输入。[逐文件独立实现复核](../originality/README.md)
