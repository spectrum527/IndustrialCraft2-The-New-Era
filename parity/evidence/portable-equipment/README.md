# 便携设备对照

参考端运行 Forge 43.5.0 和修复版 1.2.4。观测器在独立的超平坦专服调用原生点击、装备刷新和受伤入口，以公开电力接口读取使用前后的 EU。完整输入输出在 [reference-1.2.4.json](reference-1.2.4.json)。

| 情形 | 参考端观察值 |
| --- | --- |
| 电动树脂提取器成功采胶 | 50 EU，胶孔由湿变干 |
| 电动扳手转向和拆卸 | 转向 100 EU，拆卸 1000 EU。选中当前朝向时拆卸，蹲下时使用点击面的反面 |
| 风力计的空气和风力发电机读数 | 50 EU。没有转子的风力动能发生器拒绝读取，耗电 0 EU |
| 纳米剑 | 16 EU 可开启，切换耗电 0 EU。手持开启时每 16 游戏刻消耗 64 EU，命中耗电 400 EU。充足电量下攻击加成 20，其余为 4，两种状态的攻击速度修正均为 −3 |
| 普通 10 点伤害，满纳米套装 | 20 护甲值，生命减少 4，四件装备各消耗 12,500 EU |
| 普通 10 点伤害，满量子套装 | 20 护甲值，生命减少 4，四件装备各消耗 50,000 EU |
| 护甲的电量下限 | 每件纳米装达到 5,000 EU、量子装达到 20,000 EU 时提供 3/8/6/3 对应护甲点。低于下限时单件提供 2 点韧性并仍可耗尽送入的电量 |

护甲记录包含 240 组公开装备数据和受伤后实测值。受伤源使用原版仙人掌，避免和平难度将生物攻击折算为零。每次调用伤害入口前先刷新原生装备属性和生命值。
