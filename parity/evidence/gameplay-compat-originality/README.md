## 逐项复核摘要

- 箱体拆卸经正常破坏和战利品路径处理，拥有者与库存使用各宿主的数据组件或存档 API。26.x 初审的八行命中只有语法闭合边界和宿主覆盖注解，恢复逻辑改为早返回。冻结版新增与修改源码的八行命中为 0 组。
- TOP 保留固定的 IMC 消息协议，探针使用本方 EU、流体、载具及设备读数。初审确认 EU 数值格式化体重合后独立改写，冻结版与修复版的保留标识符连续词元峰值由 20 降至不足 16。
- Curios 的槽位注册与活动装备读取使用宿主 API。按功能槽取堆栈、去重、胸甲优先查找，以及充电和推力扣费由本方设备逻辑实现。
- 工坊的槽位和 UI 来自本方菜单及布局，原生 3×9 背包循环是连续词元峰值之一。比例适配和电解机的能量进度使用各自的视口和设备模型。
- 磁化机按刻采样玩家的位置并发出运动同步包。Forge 能量路由按本方图的缓存路线轮转目的地。运输与能量旧代码的原生坐标调用和通用循环单独核对。
- 高分短文件包括界面与能力适配、可选模组安装入口和只读数据接口；复核检查了其声明、平台回调和实际执行范围。A26 只采用已有固定路径与摘要清单。
