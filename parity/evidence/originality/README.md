## 高分与八行记录

- `CellItem.java` 有 3 个参照文件命中连续八行，共 8 个相同窗口。命中范围为 import 区。详见逐文件分类和执行体裁决。
- 新增或修改源码的八行命中为 0 组。
- `PanelButton.java` 的原始最高分为 46.48%。执行体只有 19–21 词元，主体是宿主 Button 构造入参转发，绘制覆盖为空。保留标识符的最大片段不足 16。
- `MenuTransfer.java` 的长归一化窗是槽位剩余容量和源数量的最小值。候选将合并与占用空槽分成两轮，且两轮分别检验槽位的活跃与准入条件。
- `MachineMenu.java` 和 `ScannerMenu.java` 的较长片段位于原生玩家 3×9 背包绑定。候选的加工读数、物品槽角色和矿物分页分别由自己的菜单状态驱动。
- `PanelGraphics.java` 的冻结增量从各宿主的流体注册表读取原生精灵及染色。三个版本使用各自的绘制接口，共同实现本方画布契约。
- A26 使用原有固定路径和 SHA-256 清单，本次仍实际应用于 `package-info.java`。逐文件记录保留应用前状态和是否匹配。

## 先前重写的回归

- `TransportBlock.java` 对修复版的执行体分数由先前重写前的 32.54% 降至冻结版的 21.72%。作者界面增加坦克升级与容器交互，管道碰撞仍按三轴组合缓存。余下最高归一化窗位于宿主方向属性表。
- `ForgeLootAdditions.java` 对修复版的执行体分数由先前重写前的 50.47% 降至冻结版的 14.55%。冻结版仍在 Forge 加载事件按本方箱子清单增加战利品池，较长片段为原生构建链。
