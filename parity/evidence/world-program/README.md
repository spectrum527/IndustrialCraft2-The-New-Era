# 首发候选世界、农业和机器升级实测

四个平台的 `0.1.0` 候选分别安装到独立专用服务器。各 JSON 记录装入的 JAR 文件名、SHA-256、种子和逐条结果。NeoForge 的 Gradle 验证任务逐字节比较装入的 JAR 和构建产物。Forge 的验证脚本比较 SHA-256，并由运行中的 ModList 确认路径。冷启动沿用各自第一个服务器写出的存档，进程号独立。

世界设备用例覆盖作物架的耕地要求、杂交、遗传种子、收割、监管机从相邻流体端口拉水、泡沫喷涂与固化、脚手架、施工饰面、绝缘线供电路径、采矿与排出、蘑菇地形、批量合成、定向分流和区块加载。自然世界以固定种子找到玄武岩、铅矿、铀矿及各自深层变体。NeoForge 运行还检查了锡矿生成及橡胶树苗生长。冷启动恢复了作物遗传数据以及装有升级的机器已付 EU 和加工进度。

基础机器保留旧输入、输出和电池槽，新菜单额外提供四格升级槽。两次原生观测检查了 `150/300 → 105/210` 进度重算以及 `3 EU/t` 耗能。玩家可配置高级拉取和定向弹出。独立断言在六个方向都验证管道相连时仅公开输入和输出。实验作物监管机验证了流体拉取，先进采矿机验证了红石反相。

复测可运行三个 NeoForge 目标的 `runNativeGameplayWorldCold` 及 `runNativeGameplayNatural`。Forge 独立发行工作树运行 `src/forge/1.19.2/qa/packaged_world_program.py`，`--cold` 复测存档，`--natural` 单独验证自然世界。这组证据记录专用服务器上的交互、状态、产出和保存结果。图形客户端、全部 52 个作物的逐品种遗传概率及远程接口实际宿主仍需独立证据。远程接口升级保留创意物品登记。水、熔岩饰面采用原版流体纹理，使用树脂片与对应流体桶制作。

## 染色、饮用和铱探索

`food-and-paint-*.json` 对应包含注册表、染线、咖啡和铱箱的新一轮独立安装。每个版本用实际剪切后的电路供电驱动作物收割机。红蓝不同色线路保持断开，黑色重新连接，两个同色分支恢复传输。用泡沫包裹后的线路仍按原色传电。冷进程从世界文件恢复所有测试颜色。

三种咖啡各实喝八杯，逐杯归还空杯。急迫和速度首次持续 300 tick，后续冷咖啡增加 600 tick，两种热咖啡增加 1200 tick，依修复版实际叠加和效果上限验收。地疣在饱食状态下可食用，只移除有害效果。奶疣、油莓和 Ranks 浆果沿用食材行为。肉类罐头即时增加 1 点饥饿值，消耗一份，无空罐容器。

`reference-1.2.4-painter-food.tsv` 和 `reference-1.2.4-iridium-chests.tsv` 为独立启动的修复版运行记录，JAR SHA-256 为 `c3801301c8f32f957dd879413d33826438004f5a54f56fb17a2903da820efc5e`。铱箱每类按固定种子序列采样 8000 次。候选用独立附加战利品池拟合箱型、出现率与单栈范围，精确抽样序列及箱内余量分布尚无等价证据。候选从实装 JAR 开箱确认八类有铱碎片、四类另外有整铱矿、沉船阴性，箱中原版战利品仍可取得。

NeoForge 用各目标的 `runNativeGameplayWorldDetailsCold` 复验。Forge 用 `src/forge/1.19.2/qa/packaged_world_program.py --details --cold`。注册明细和生存路径见 [registry/acquisition.tsv](registry/acquisition.tsv)，包摘要和 SHA-256 见 [registry/summary.json](registry/summary.json)。
