# 行为参考 · Reference versions

本项目对照 IndustrialCraft² Experimental 2.9.40、2.8.222 以及修复版 1.2.4 的可观察玩法。Spec 角色把输入、输出和边界写成行为规格，开发与测试使用这些规格。原始源码、游戏文件和内部资料由独立私有参考工作区保管。

The clean-room specification team uses these versions to describe observable inputs, outputs and edge cases. This public index links to the resulting specifications and audit evidence.
