# IndustrialCraft²: The New Era 1.0.6 游玩指南

创造模式中，游戏内容分布在机器、供电与布线、核工业、工具与护甲、材料与部件、流体与容器、运输与储存、农业与建筑八个标签页。

## 安装

选择与游戏版本对应的加载器，把同一份 JAR 放入客户端和专用服务端的 `mods/`，创建新世界。单人游戏只需安装客户端。重建版与修复版都注册 `ic2`，请为两套模组分别使用独立实例和存档。

## 第一条生产线

1. 在新生成的森林、丛林或平原及其变种里寻找橡胶树，对着有树脂的树洞使用木龙头。下矿取得铜、锡和铁，用熔炉和工作台准备橡胶、导线、电池及机壳。树洞、树苗和矿层都能通过正常世界生成取得。
2. 制作火力发电机、绝缘铜导线和打粉机。给发电机放煤，将导线连到机器。可以在中间加入 BatBox，用扳手将其输出面朝向用电端。发电机每块煤提供 4,000 EU。
3. 将一块煤放进打粉机，稳定供电 300 个游戏刻可得一份煤粉，共耗 600 EU。接电炉、提取机或压缩机时，留出产物空间。断电会保留已付费的加工进度。
4. 将物品管接到输出库存，把液管和泵盖接在可装卸的液罐面。先用一桶水或一组空单元试流向，再接入洗矿、装罐或电解设备。矿物加工产生的主产物和副产物都要有去处。

普通和电动扳手会在准星所在面显示操作区。点蓝色边区向相应方向转动，点红色中心拆卸。木、铁、青铜、钢四种储物箱有各自的箱盖、侧壁和底板。导线可含水，用桶进出水，拆线后保留水源。

取得树脂、粗锡或木龙头可解锁工业进度树。28 项覆盖设备、运输和装备。放置、穿戴及带电工具命中按实际操作授予，经验每项只发一次。

## 工业发展

| 想做的事 | 设备与操作 |
|---|---|
| 冶炼和提高产率 | 打粉机处理矿料，洗矿机同时需要水和 EU，热能离心机需要达到工作温度。金属成型机可选挤压、轧制与切割。 |
| 从铁得到钢 | 用热源对准高炉受热面，向炉内供空气并放入铁锭。预热后每份钢需工作 6,000 刻，同时产出炉渣。 |
| 分配和变换电力 | 从 BatBox、CESU 逐步升级到 MFE、MFSU。变压器按标记面接线，潜行操作可切换红石控制、固定降压与固定升压。 |
| 运输物品和流体 | 青铜、钢两套管道各有四种尺寸。储罐、泵盖和分配器配合使用。机器也能安装适用的弹出、拉取和过滤升级。 |
| 自动生产和储物 | 批量工作台保存合成模板。分拣机按物品和出口分流，加权分配器可设优先级。可搬运的储物箱挖下后保留库存，铱箱以 18 列、7 行显示全部 126 格。 |
| 农业与采矿 | 在作物架上培育、杂交及分析作物，用作物监管机和收割机维护农场。普通采矿机需钻头和采矿管，高级采矿机可设筛选与红石控制。 |
| 热能和动能 | 焦炉可同时取得固体产物与杂酚油。蒸汽机需要稳定热源和水，蒸汽进入涡轮后可经动能发电机供电，冷凝器回收排汽。 |
| 水力动能 | 把**水力动能发生机**的整个叶轮浸在水里。独立人工池提供 4 KU/t，水路接通天然河流、海洋或深海后可分别提供 150、300 或 400 KU/t。河流档经动能发电机可输出 37.5 EU/t。水道可以弯曲或跨越生物群系。河海一端须连到至少 64 个相邻的天然水柱，东西或南北方向至少横跨 16 格，冰下水也计入。青铜、铁、钢、碳转子分别需要半径 2、2、3、4 格的轮面空间。把动能发电机的输入面对准水机背对叶轮的一侧，再接上储电箱。水机可以空载转动，接入负载后才向外送出 KU。 |
| 风力动能 | 把转子放入风力动能发生机，在叶片一侧留出旋转空间。机器背对叶片的一侧输出 KU，让动能发电机的动能输入面贴住这一侧，再给发电机接上有余量的储电箱或用电设备。风机界面显示当前可提供的 KU/t，动能发电机按实际取到的每 4 KU 转换为 1 EU。 |
| UU 复制 | 扫描机完成样本扫描，将图案存入模式存储机，随后给复制机供应液态 UU 与电力。可选单次和连续复制。 |
| 量子装备充电 | 量子头盔、胸甲、护腿和靴子每件可存 10,000,000 EU。单件放进 **MFSU 储电箱**上方的充电槽，或站上有电的 **MFSU 充电座**，身上穿着、手持和物品栏里的装备都会补电。悬停在装备上可看到电量和所需的 4 级充电等级。经典 MFSU 为 3 级。 |
| 玩家装备 | 从电池和充电槽给电动工具、喷气背包、纳米及量子装备补电。EU 表可在运行中的机器与导线上观察实际输入、输出和电压。 |
| 传送与交易 | 用同一个频率变送器依次操作两个传送机，起点旁放入有电的储能设备并给红石信号。交易机从相邻库存取货和收款。 |

纳米或量子装备同系列穿齐、四件都有足够电量时，整套扣电吸收伤害。耗尽后，纳米套护甲值为 0，量子头盔、胸甲、护腿、靴子分别提供 2、4、2、2 点。全套量子装备带电时还会提高暗处和水下的亮度，并将挖掘速度乘以 1.4。这两项能力独立于药水效果。

## 机器界面

打开设备界面，点击面板外侧的齿轮图标，打开「六面权限」。上、下、左、右、前、后均相对机器，弹窗同时标明世界方向。将产物侧设为「仅出」，原料侧设为「仅入」。禁止的一面会断开物品管和流体管；电线、玩家打开机器和手持桶或单元取放仍按原规则。旧存档的六面默认全部开放。

漏斗、管道和机器升级会把有效原料送入对应的输入格，把可供电的电池送入兼容的电池格。抽取时只交付成品。例如，打粉机下的漏斗能收走煤粉，未打碎的煤、供电电池和升级仍留在机内。充电设备工作格里已充满的电池，以及反应堆中已耗尽的燃料棒，都能从原格取出。

在 2×2 工作格中无序放入两个青铜外壳、一根极细青铜流体管，再放一个活塞可得管道抽吸嘴，换成投掷器可得管道注入嘴。手持管嘴点管段朝向机器的接口，用撬棍拆下。物品、流体两类管道都能使用这两件配件，外形随四种管径和青铜、钢材质变化。抽吸嘴把机器允许取出的物品或流体抽进管中，注入嘴把管中资源送进相邻机器可接收的位置。同一面不能叠装管嘴或泵盖。

管嘴与机器上的升级按面配合。抽吸嘴挡住该面同类资源的抽入升级，注入嘴挡住该面同类资源的弹出升级。其他面仍可搬运。四档物品管最高每刻分别送 1、4、16、64 件；四档青铜流体管分别为 20、40、120、240 mB/t，钢管为 40、80、240、480 mB/t。多个管嘴共用该管段的吞吐量。

金属成形机中间的按钮切换轧制、挤压和切割。洗矿机用水单元或水桶预充 8,000 mB 的水罐，空容器从下方取出。每份矿用水 100 mB，满罐洗完一份余 7,900 mB，到 7,000 mB 时再打开一枚 1,000 mB 水单元。电动设备上带闪电标记的放电格可以接入相应等级的蓄电物品，半流体发电机可反向给物品充电。泵能将存储的水装入空桶。工业工作台上方两组槽位分别用于锻造锤和剪线钳，下方保留 18 格材料。中央的红叉把九格合成区的材料退回玩家。

一枚一次性电池含 **1,200 EU**，放电槽可放一整叠。储电箱等容量至少 1,200 EU 的机器，空出 1,200 EU 才用一枚。普通电炉总容量为 600 EU，有空位就用一枚并充满，多余电量舍弃。机器满电时保留槽内所有电池。

储能设备和变压器可在界面里切换红石模式。储罐中央的液格显示当前流体，拿起桶或单元并点击可灌入或取出。普通储罐右边有四个升级位，可配合液体拉取和弹出升级指定方向。物品分拣机、加权分配器和便携箱上的翻页按钮会保留同一个容器中的内容。

将锡质外壳、玻璃板、锡质外壳横排在工作台上，一次可得 **4 个基本液体单元**。它们只容纳水和熔岩，每个装 1,000 mB。用手、泵或灌装设备装满后，成品分别是**基本水单元**和**基本熔岩单元**。

将 4 个锡质外壳排在玻璃方块上下左右，可得 **1 个通用流体单元**。它能装水、熔岩和工业流体，也用于制作压缩空气、除草剂和经典燃料等单元。机器倒空或工作台拆解后，取回对应的基本或通用空壳。手持装满的单元右键储罐或机器进液面可注入，右键普通方块会保留液体。

焦炭窑需要 3×3×3 中空耐火砖壳。主方块在正面中央，窑口在顶面中央，炉篦在底面中央。成形后正面出现钢箍，只从主方块手动投料、取物和用桶取油，顶底端口留给漏斗和流体管。煤产一份焦炭和 500 mB 杂酚油，原木产木炭和 250 mB。

链锯与普通、钻石、铱钻头的带电基础伤害依次为 10、6、7、8 点，实际打伤生物后分别扣 100、50、80、800 EU。切换镭射枪时可看到模式名和每发耗电。纳米剑使用短促的开机声和命中声。

## 经典设备

经典装罐机、电解机、物质制造机、MFE、MFSU、作物监管机和经典核装置可与实验版机器共存。电解机、物质生成机和 MFE 的两套原始布局完全相同，先按原布局合成实验版，再把成品单独放入工作台即可选用经典机型。其余经典机型使用修复版所附 Classic 配方表中的对应布局。植物球和水合煤粉可在压缩机处理，再经单元、提取机和经典装罐机走完两条燃料路线。

通用储罐、UU 合成台和两个高级物品搬运升级各有一条重建版生存配方。铜锡合金粉、青金石粉、钻石粉、黑曜石粉和铀-238 也可按 1∶9 拆小份。[经典及补充配方](../spec/registry/classic-playable-recipes.json)

### 兼容材料的生存入口

原始登记中还保留了少量旧材料和供其他模组使用的矿样。重建版在工作台提供了下列补充配方，原有机器配方仍可以照常使用。

| 物品 | 取得方法 |
|---|---|
| IC2 铜锭 | 将原版铜锭放入工作台转换。 |
| 锂燃料棒 | 在工作台组合空燃料棒和游戏中的锂粉。 |
| 两种核燃料靶丸、建筑泡沫颗粒 | 将对应的铀燃料、MOX 或建筑泡沫粉放入工作台即可换成颗粒，颗粒可换回等量原料。 |
| 除草剂桶 | 组合已制成的除草剂单元和空桶；桶可给作物监管机供液。 |
| 重水桶、粉碎银矿 | 重水桶使用一份固态 UU 物质、水单元和空桶。粉碎银矿使用一份固态 UU 物质和银粉。银粉可从金矿加工的副产物积攒，粉碎银矿随后可正常洗矿。 |

## 游戏内反应堆

先用一根铀燃料棒验证电力堆。三个基础列可容纳部件，每个相邻扩展仓再开放一列。红石开启后，独立单棒输出 5 EU/t，每 20 个游戏刻推进一次部件磨损与热量。散热片、冷却单元、交换器和堆板有不同的用途，界面中可看到堆温及其上限。

流体模式需要六个扩展仓和完整的 5×5×5 反应堆外壳。访问口用来装部件，流体口接收冷却液、排出热冷却液，红石接口用来启动。单棒配相邻反应堆散热片时，六个工作周期可将 48 mB 冷却液转为热冷却液。游戏里的放射性物品可存入屏蔽盒，防化服需穿齐才能提供对应防护。
