# Industrial Age 2 项目章程（P0-T1）

> **负责人于 2026-11-12 确认 G0 通过，以下 39 项作为 MVP 范围基线**（A20）。评审与后补项见 [G0 记录](gates/G0.md)；G1、G2、G5 仍分别验收。

## 目标与交付边界

建立从采集材料、制作基础零件，到发电、输电、储电和机器加工的可玩工业闭环。mod id 为 `ia2`，包根与 Maven group 为 `com.industrialage.ia2`。核心行为依据已评审的规格净室实现；不承诺逐项 1:1 复刻。

以 NeoForge 1.21.1 为主基线，同时维护 NeoForge 26.1 编译目标；MVP / G5 在主基线验收，同步目标从 P6 纳入运行验收（A5）。本次确认不扩大 MVP 清单；新增内容仍按后续阶段与规格评审执行。

## 三层范围

| 层级 | 范围 | 交付判断 |
|---|---|---|
| MVP | 下列 39 项候选；橡胶与锡矿、基础材料、发电机、1 级线缆、BatBox、四台加工机器、基础工具与装甲，以及必要的 GUI / JEI | 无电材料能启动供电链；机器加工和基础装备路线可玩，G5 验收通过 |
| v0.5 | 扩充 Tier 1–2 机器、金属成型、洗矿、流体系统、储电与变压、充电台和更多工具 | 工业材料链完整；纳入已批准的蒸汽焦炉链、流体管道与泵盖板、泡沫喷枪玩法（C-MF1/2/5）；MVP 门禁通过后推进 |
| v1.0 | 反应堆、作物、UU 链、高级机器、高级装甲、传送与地形改造；纳入已决定的修复和盖板重新设计 | 纳入交易终端与 C-MF8 的 v1.0 内容池；按各阶段门禁验收，不将挂起或砍掉项重新纳入 |

版本层级表示递进范围，不是发布日期承诺。铅、铀等不服务当前 MVP 闭环的内容留到相应工业链需要时评审。

## 不做什么

- 不直接搬运参考实现、注释或反射架构；不承诺旧版二进制、存档及数据包兼容。数据兼容议题留到 v1.0 后评估。
- 不移植粒子加速器（B#22）；雷管不进入 MVP，按覆盖 B#25 的 C-MF8 留在 v1.0 内容池。
- 不做无线交易市场；本地交易机仍保留在后续范围中（B#26）。
- 不保留废弃的 GUI 显示 / 效果子包，也不复制网络反射序列化（B#31）；界面使用统一体系及必要的手写例外（B#8）。
- 电动力机挂起，MVP 至 v1.0 不移植；保留 kU 接口，v1.0 后评估新消费者（B#33）。盖板按 B#23 重新设计为真功能，不能当作砍掉项。
- 不实施真正异步的能量计算；同步计算并预留可插拔接口（B#6）。不重建 33 个死配置键，也不做旧键兼容层，只保留 58 个活键和后续迁移文档（A10）。
- MVP 至 v1.0 不发布 Fabric；不把 1.19.2 参考实例变成发布目标（A5 / A6 / A20）。
- 不使用未授权的名称或商标作项目标识；对外措辞遵守 A15。
- 转 Public 前只做邀请制封闭测试，不向公开模组平台发布（A13）。原版素材永不进入主仓库历史，公开前全部替换为新作（A7 / A21 / A22）。

## 门禁与未完成事项

- G0：负责人已于 2026-11-12 确认通过并授权 P2 开工；平台、构建与参考运行已有证据。授权原文和私有基线快照文档继续跟进，不将其写成已收齐。
- G1：每个 MVP 条目均有规格，输入 / 输出 / 边界 / 失败模式齐全；逐场景准备可重复的 parity 输入及真实期望值。
- G5：在主基线完成采集到加工的可玩链路，并通过能量、机器、配方、界面和保存 / 加载验收；失败不得直接进入内容扩张阶段。
- 与批准范围关联的决策 B 修复项必须落到对应实现任务和回归用例。尚未实测的行为不能标为通过，也不得用模板示例代替采样结果。

39 项范围按本次 G0 确认成为基线；具体首批配方与数值仍以已评审规格为准。如新增条目，须重新检查依赖与 40 项上限。背包供电、太阳能装备和作物分析器等 C-MF8 第一批项目在 MVP 后按 P6/P7 对应任务推进；新增范围不提前进入 P2。
