## 复跑

```sh
./gradlew clean build --no-build-cache
python3 src/forge/1.19.2/qa/verify.py all --output build/forge-p2-acceptance
python3 -m unittest discover -s tools/similarity -p 'test_*.py'
```

完整客户端验收需要图形会话。运行器为每轮创建新的证据目录，保存各进程的日志、结果和真实世界状态。发行包专服复测使用已有的 Forge 安装及其 EULA 文件。

```sh
python3 src/forge/1.19.2/qa/packaged_server.py \
  --jar src/forge/1.19.2/build/libs/ic2-forge-1.19.2-0.1.0-SNAPSHOT.jar \
  --libraries /path/to/forge-server/libraries --eula /path/to/forge-server/eula.txt \
  --directory build/forge-p2-packaged
```

P3 的能量网、P4 的机器框架及之后的生存内容、存档迁移和发布测试继续按各阶段验收。
