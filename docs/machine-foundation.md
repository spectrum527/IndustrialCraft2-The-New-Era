# 第一台机器的燃烧与存档验收

2026-11-20 在 G2 主线 `10a57ba` 上开始 P3-T1 和 P4-T1。火力发电机的燃烧、储能和存档进入两个 NeoForge 开发包。1.21.1 使用测试模组登记方块和燃料槽，驱动生产方块实体。玩家可取得的 `ic2:generator`、合成配方和界面留待内容任务接入。

## 一块煤跨两次开服

1.21.1 专服用方块物品在主世界 (29, 90, 25) 放置机器。先放岩浆桶，机器空闲，桶仍在槽内。换入两块煤，默认每个工作刻产生 10 EU。两个进程均正常退出。

| 时点 | 本进程累计工作刻 | 剩余燃料刻 | 储能 | 槽中剩煤 |
| --- | ---: | ---: | ---: | ---: |
| 第一次关服前 | 37 | 363 | 370 EU | 1 |
| 第二个进程从同档读入 | 0 | 363 | 370 EU | 1 |
| 首块煤烧完、满仓空闲 | 363 | 0 | 4,000 EU | 1 |

满仓时请求 64 EU，机器实际给出一包 32 EU，余 3,968 EU。拆除方块后，旧引用再请求得到 0 EU。此处直接调用机器出电端。发电机经导线向实际受端供电由 P3-T2～T5 接续。

## 已交付的代码

- 每个世界独立维护六面有向能量图。设备各自收发，导体连通两端。测试覆盖拆线、环路绕行、重接、不同维度同坐标和等级包量。路径损耗与每轮实收结算属于 P3-T3。[能量网络规格](../spec/energy/network.md)
- 方块实体驱动组件加载、服务端逐刻和卸载。同步拆机会中止其余回调，加载失败会释放已加载组件。持久状态变更时通知宿主存盘。[组件生命周期](../spec/machines/components.md)
- 火力机通过宿主查询实际熔炉燃料值，每 4 个原始燃料刻折合 1 个工作刻。两版采用同一份存档格式保存余燃料及双精度 EU。回归逐项核对燃烧计量、槽内煤数和重启后的余量。[能量设备规格 §2、§5](../spec/energy/devices.md)

## 本地复跑

```sh
./gradlew --offline --no-build-cache clean build :test:runPlatformHostTest :test:runGameTest :test:runPlatformWorldTest
```

两版开发包均通过字节和夹具隔离校验。共同及构建 JUnit 40/40，1.21.1 宿主契约 5/5，专服 smoke 1/1。两进程回归的写入和读回阶段分别通过 37、16 项断言。位置、燃料、煤数、电量和进程号在 1.21.1 模块的 `build/run/platformWorld/{write,read}.properties`。26.1 本轮验收到编译和打包。

私有三基线比较覆盖 53 个候选和 3,012 个参考文件，159,636 次比较。18 项通过、35 项警告、0 项失败，连续八行命中为 0。
