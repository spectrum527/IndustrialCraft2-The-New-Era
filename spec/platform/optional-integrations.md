# 探针读数与背饰装备

## §1 安装组合

IC2 的客户端和专服均可独立运行。安装 The One Probe 后，玩家可在探针界面查看 IC2 设备读数。安装 Curios 后，玩家可在背饰栏装备 IC2 背包。两项功能分别按对应模组的安装情况启用。

## §2 The One Probe

读数取自玩家指向的服务端方块或实体。储电设备按 EU 显示当前储能与容量。储罐按 mB 显示液体种类、存量和容量，多储槽设备分别显示各槽。空罐保留容量信息，设备工作或被抽取后，下一次探测能读到更新值。

电动船使用骑手装备的电池供电时，读数标明这份电量属于骑手电源。设备内部储能、发电速率和通过导线的能量使用各自的含义和单位。

## §3 Curios

`batpack`、`advanced_batpack`、`energy_pack`、`electric_jetpack` 和 `jetpack` 可以装入 Curios 的 `back` 槽位。前三种电池背包可在背饰位供电，电力和燃油喷气背包可在背饰位飞行。胸甲栏也有适用装备时，优先使用胸甲栏里的那件。

玩家站上合适等级的充电座后，四种电力背包按物品容量、充电等级和座内储能结算。电量写回背饰栏里的原物品，充电座扣去相同数量的 EU。同一件装备每轮只结算一次，取下后保有已充入的电量。燃油喷气背包沿用其燃油补给方式。

## §4 JEI 与 EMI 配方查看器

安装 JEI 或 EMI 后，IC2 通过统一配方目录向配方查看器注册全部 18 类机器分类：

- 基础加工（4 类）：打粉机（`macerator`）、压缩机（`compressor`）、提取机（`extractor`）、金属成型机三模式（`metal_former_rolling`、`metal_former_cutting`、`metal_former_extruding`）。
- 车间与装罐（6 类）：洗矿机（`ore_washer`，含水流体输入）、热力离心机（`centrifuge`）、高炉（`blast_furnace`，含压缩空气流体输入）、切块机（`block_cutter`）、装罐机灌装（`canner_bottle`）与流体浓缩（`canner_enrich`，含输入流体、固相添加物与输出流体）。
- 热工、废料与物质（6 类）：焦炭窑（`coke_kiln`，煤与原木分别产出焦炭/木炭与杂酚油）、回收机（`recycler`，标注 12.5% 废料概率与黑名单语义）、电解机（`electrolyzer`，水电解产出氢气与氧气）、发酵机（`fermenter`，生物质转沼气与肥料）、质量发生器（`mass_fabricator`，废料/废料箱增幅与 UU 物质产出）、UU 组装台（`uu_assembly`，模板与 UU 物质消耗）。

标签输入规则：配方目录保留 `#tag` 元数据；在 JEI 中通过 `addRichTooltipCallback` 显示原标签标识，在 EMI 中优先以带数量的 `TagKey` 或保留堆叠数的多候选项构造 `EmiIngredient` 并附加标签提示。单次注册构建内共享标签成员缓存，避免重复全表扫描。

## §5 实测

在各目标加载器分别运行 IC2 单独安装、仅加 The One Probe、仅加 Curios 和两者同装四种组合，以及附带 JEI / EMI 的客户端启动校验。探针读取有液与空罐、有电与用电后的设备及电动船。背饰测试从实际装备栈读取充电前后电量，并核对充电座的差额。配方查看器核对 18 类分类注册、流体槽显示、标签提示与堆叠数保真。
