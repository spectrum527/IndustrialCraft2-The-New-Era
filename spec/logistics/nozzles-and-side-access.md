# 管道抽吸嘴、注入嘴与设备面权限

1.0.6 的两种管嘴与六面权限来自维护者的新玩法设计。运输容量、速率、在途资源及保存要求沿用本项目的[管件规格](pipes.md)和[路由规格](routing.md)，其中的修复版数据只用于原有管道行为。

## §1 管嘴合成与装拆

| 物品 | 2×2 工作格无序合成材料 | 产量 |
|---|---|---:|
| 管道抽吸嘴 `ic2:pipe_extraction_nozzle` | 青铜外壳 ×2、极细青铜流体管 ×1、活塞 ×1 | 1 |
| 管道注入嘴 `ic2:pipe_injection_nozzle` | 青铜外壳 ×2、极细青铜流体管 ×1、投掷器 ×1 | 1 |

两件物品位于「运输与储存」创造分类，英文名称分别为 Pipe Extraction Nozzle 和 Pipe Injection Nozzle。两种管嘴均可安装在青铜、钢的四种管径上，覆盖八种物品管与八种流体管。安装时选中管段的一面，该面接触的设备即为管嘴的出入端。按管径、材质显示贴合的管嘴，箭头沿安装面分别指向管内和管外。同一管段的不同面可独立安装，每面只容纳一件管嘴或原有的盖。先装者占位，重复或交叉尝试保留手持物及原装件。拆下管嘴可取回一件，空面重复操作无新增产物。管嘴的种类和所在面随管段保存。

## §2 管嘴方向、速率与守恒

- **抽吸嘴**从相邻设备该面的原生可取端口取出资源，送入管段。**注入嘴**把本段资源送入相邻设备该面的原生可存端口。装嘴面按管嘴约定单向交接，无嘴面沿用设定流向、原有分流与盖的行为。物品管承载物品，流体管承载流体。端口方向、设备面权限和资源类型须同时允许。
- 管嘴沿同材质、同管径的单段容量和原有速率工作，多个管嘴共用该管段的既有容量与运输预算。单端连续供料并有足够末端空间时，物品上限按四种管径为 1、4、16、64 件/t。青铜流体上限为 20、40、120、240 mB/t，钢流体为 40、80、240、480 mB/t。带泵盖的原有路径仍受其额定值及管段限制。[逐刻速率与启动样本](routing.md#rate)
- 模拟试收、容量不足、资源身份不兼容、端口拒绝或邻区块未加载时，源端和在途缓冲保存未交付资源。部分接收按实收量结算。物品按完整栈身份结算，保留名称及组件或 NBT。流体按完整资源身份及 mB 结算，避免并液和替换。恢复空间、面权限或连接后，最后一件或 1 mB 也可继续交付。

## §3 设备的六面自动化权限

玩家从设备向外看其前面。前对应设备原生工作朝向，后为反面，左、右按此视角确定。没有可用朝向的设备以前北为基准。图中的上、下是设备的相对面。横向朝向时，上、下对应世界上、下。有原生竖向朝向时，采用下表的固定转动方式。转向后的标记与权限随设备一起变换世界面。

| 前对应世界面 | 后 | 左 | 右 | 上 | 下 |
|---|---|---|---|---|---|
| 北 | 南 | 西 | 东 | 上 | 下 |
| 东 | 西 | 北 | 南 | 上 | 下 |
| 南 | 北 | 东 | 西 | 上 | 下 |
| 西 | 东 | 南 | 北 | 上 | 下 |
| 上 | 下 | 西 | 东 | 南 | 北 |
| 下 | 上 | 西 | 东 | 北 | 南 |

| 模式 | 自动化从设备存入 | 自动化从设备取出 |
|---|---|---|
| 全 | 允许原有可存资源和槽 | 允许原有可取资源和槽 |
| 禁 | 禁止 | 禁止 |
| 仅出 | 禁止 | 允许原有可取资源和槽 |
| 仅入 | 允许原有可存资源和槽 | 禁止 |

上表从设备侧理解，即「存入」为外部进入设备。权限与设备原有的端口、面别、锁定及[机器物品槽的规则](#automation-slots)同时生效。管口、管盖、漏斗、设备自身升级以及通过版本原生物品或流体接口交接的其他自动化都执行相同的条件。

禁用面立即停止物品和流体交接，面对它的管口移除连接臂，已安装的管嘴仍留在原处。重新允许相应方向时恢复连接和待送资源。电力线仍按既有方向、连接、等级和传输规则工作，物品和流体权限不参与电气判定。

维护者已确认权限只管自动化和管道。玩家手持桶或单元对开放端口取放、经设备界面手动取放、合法打开设备菜单，都沿用各自既有行为及原有所有权限制。关闭六面后的设备也可由有权玩家继续操作菜单及重新开放权限。

## §4 同面升级避让

| 装在相邻管段且朝向设备的管嘴 | 该设备同面暂停的自动化升级方向 |
|---|---|
| 抽吸嘴 | 抽入升级的取入动作 |
| 注入嘴 | 弹出升级的排出动作 |

普通和高级物品升级，以及对应的流体抽入与弹出升级均执行同一约定。管嘴与升级须处理同一种资源，且位于同一个交接面。管嘴暂时无料或下游满载时，同面的相应升级仍避让。设备其他面的升级和同面方向相容的动作继续受自身原有条件与权限约束。拆下管嘴后，该面按储量和权限恢复原来的升级动作。

## §5 界面、保存与服务端权限

可操作的固定设备均提供六面配置入口，包括有操作屏幕的设备、储罐、储物箱和工业工作台。入口仍位于原 GUI 面板图外，按钮平时只显示绘制的齿轮图标。鼠标悬停或键盘聚焦时显示说明，中文为「六面权限」，英文为「Side access」。按钮可用键盘聚焦并确认，原生朗读使用同一说明。

从入口打开六面弹窗，可读取与选择各面的「全、禁、仅出、仅入」。原面板图、物品栏与设备操作区域保留。弹窗显示服务端确认后的值。

服务端以当前打开的合法会话为依据，核对玩家的设备访问权限和距离、设备是否仍为同一有效目标，以及面和模式是否合法。未经授权或失效会话的更改请求保持原值。每面状态独立保存，旧存档或新设备默认六面皆为「全」。保存、区块卸载、换进程重进和设备转向后仍能得到对应的相对面值。

## §6 四版验收矩阵

| 场景 | 操作与通过条件 |
|---|---|
| 生存合成及 16 种适配 | 对照两条实际合成配方。两种管嘴均能在每种管上安装，核对占位、不同面并存、与原有可装盖互斥、拆卸返还和重加载后的朝向。 |
| 物品与流体实流 | 以两种材质和四种管径测可持续单端速率。分别做带不同数据的同 ID 物品、同液与异液、部分空位、满端、断线、区块卸载、冷启动及续送。逐处对账并检查末件和末 1 mB。 |
| 面模式与底层规则 | 每面四态实测存入与取出，覆盖漏斗、带嘴和无嘴的管口及版本原生资源端口。在开放面仍拒绝原本不可写的材料、输出槽和不允许的方向。 |
| 设备朝向和旧档 | 从原有存档读到六面皆全。水平设备转一周，原生支持竖轴的设备转到上、下，无方向设备保持前北。配置随相对面转动，保存和重启后仍一致。 |
| 反向升级避让 | 普通与高级抽入和弹出、流体对应升级分别测同面相斥、不同面照常、同面相容及异资源照常。带嘴面暂时空载也须避让，移除后恢复。 |
| 视觉、供电与真实菜单 | 在四版实机切换面权限，验证邻管断开或恢复的外形和实际运输。接着在六面全禁状态验证电力仍达设备，手持桶/单元取放、原菜单手动取放照常，可重新开启指定面。 |
| 固定设备 GUI 和授权 | 实际打开常用机器、储罐、不同储物箱及工业工作台，核对面板外的入口只显示齿轮图标。分别悬停和键盘聚焦，核对中英文说明及原生朗读，用鼠标或键盘打开原弹窗。授权账号分面改值并重开核读。非授权账号、失效会话、伪造面或模式发送的写入均保持既有状态。 |

## §7 机器物品槽的自动化规则

维护者在 1.0.6 发布前确认此规则，适用于普通物品管与装嘴物品管（抽吸嘴、注入嘴）、原版漏斗、加载器原生物品接口和机器的物品自动化升级。模拟和实际交接都检查同一方向、槽位、物品类型及当前状态。外部调用者即使知道槽号，也只能操作该面及该槽本来允许的方向。

| 机器槽位或物品状态 | 自动存入 | 自动取出 |
|---|---|---|
| 实际加工原料位 | 仅接受本机对应工序可用的原料 | 未加工原料和旧档遗留的无效物留在机器 |
| 普通加工机的供电电池位 | 仅接受本机可用的兼容电池 | 供电电池留在机器，耗尽后也按此规则处理 |
| 专用充电设备的电池工作位 | 接收本机认可的兼容电池 | 仅可取出达到该设备完成条件的物品，例如已充满电池 |
| 成品输出位 | 禁止 | 可取出该位的成品 |
| 有明确成品状态的共用工作位 | 对应工序准许的原料或电池 | 设备可检查出该格已有完成产物时可取出，例如已耗尽且确认为产物的燃料棒 |
| 升级、模板或长期组件位 | 禁止 | 保留在机器 |

§3 的权限限制实际交接方向。「全」仍要求物品和槽有效。「仅出」也必须等到可取的成品。「仅入」可补充允许的原料或电池，并拦住出料。普通被动储物箱继续按其原有库存、锁定和各面权限接收或供取物品。设备手动 GUI 仍允许玩家按原有规则处理电池、遗留无效物、升级及组件。此节约束物品槽，流体端口、手持桶/单元及供电采用 §3 的规则。

四版用运行中的机器复核以下工况。测试模拟和实际交接时分别核对机器、来源、在途管段及目标的物品数量与数据。

表中「来源保留」指本次机器交接的直接供料端，允许从被动储物箱抽出的物品可先进入管道，机器拒收时可留在到料的管段内。

| 场景 | 通过条件 |
|---|---|
| 原料、电池与无效物 | 通过漏斗、管口和版本原生物品端口送入有效原料和兼容电池，两者进入对应工作位。错误物品、拟写产物位、升级或模板的请求实收为零，来源保留物品。 |
| 原料、供电物品与产物并存 | 准备未加工原料、供电电池、升级和正常产物，再额外加入旧档遗留的无效物。使用抽吸嘴、裸管、漏斗或原生端口接收产物，机器内的其他物品留存。清空产物后无进一步可抽物。 |
| 共用位完成边界 | 尚未充满的充电电池和未耗尽的反应燃料保留在位。充满或转换成设备可识别的耗尽产物后，从同一工作位取得完整物品，交付的数据与机内确认完成时一致。普通加工机已耗尽的供电电池仍留在原处。 |
| 面权、被动储箱和手动操作 | 切换面权给出合法交接的正反例。测试被动储箱从允许面收取正常物品，并在机器全禁时用原 GUI 手动取放、重新开放一个面。 |
