# 配置装载与游戏内重载（P2-T5）

## §1 宿主与文件

两版适配器均以实际的 NeoForge `ModConfigSpec` 声明 58 项，供宿主生成默认模板并验证类型及值域。本项目为每个存档选用唯一的 `<world>/serverconfig/ic2-server.toml`。集成服务器使用所选单人存档的同一相对路径，实例配置目录不参与查找。斜线分节映射为 TOML 路径组件，UU 表中含冒号的末段作为完整的带引号键，不能被拆分。[逐键契约](active-keys.md) · [NeoForge 配置类型与事件](https://docs.neoforged.net/docs/1.21.1/misc/config/)

每次打开存档建立该会话的配置视图。初始尚未装载时读取为空。首次创建全新配置文件时按表生成 58 项默认并发布。现存文件需完整通过校验，新增文件的默认模板不能掩盖现存候选中的缺项或错值。专服及集成服的逻辑服务器消费当前视图，远端客户端本机配置无法覆盖服务器。P2 没有全量配置的客户端同步或 GUI 读取要求。

## §2 解析、校验与发布

1. 选定当前会话实际使用的文件，读取同一次稳定的完整候选。验证 TOML 结构、键路径、是否恰有全部 58 个已声明叶值、每个标量及列表元素。重复键、未知叶、缺少声明键、坏类型、不合法范围或无法读取的候选均失败。普通注释、合法空列表和 TOML 键顺序不影响结果。
2. TOML 的原生整数或实数在浮点字段按声明精度转换。整数字段只收整数。不从字符串转换，也不把 1 当作布尔值。值域见逐键表。先完成整份校验，再一次发布深度不可变的快照。校验器看到的候选与最后发布的全部值须一致。
3. 调用方已取得的快照持续可读，包括列表值。读取新快照才观察到新的配置。无效首载报告失效键或原因，当前视图仍空。无效重载保留上一次成功快照。宿主如果会纠错后补默认，适配器仍须检查原始候选，不能将自动修正后的错误文件报告为成功。成功读取与候选失败都应留下可关联的会话及结果。

## §3 运行中操作与权限

提供正常游戏内或专服控制台可调用的管理员入口 `/ic2 config reload`。权限等级至少 2，普通远端玩家不能触发服务器重新装载。成功后命令返回已应用，失败时返回具体原因。任何客户端请求都不能直接设置服务端值。正常宿主装载与显式命令经过同一套完整验证。若还接入宿主的重载事件，其并发回调也只能发布完整候选。已离开的会话不能在回调中覆盖本次存档。

一条服务器消费者在同一操作内只读一个快照，后续独立操作可取得新值。玩家在游戏中执行上述命令即可触发配置验证。原版 `/reload` 用于数据包。数据包刷新、资源包 F3+T 和配置重载分别取证。文件缺省时的默认值、某字段显式取空列表，以及文件中缺失该字段，是三种不同的输入。

## §4 QA 与 G2

| 场景 | 应观察的结果 |
| --- | --- |
| 新存档默认 | 实际登记的叶键去重后与逐键表逐项匹配，正好 58 项。检查保留率 0.8、发酵热量 4000 HU、两个 UU 值及两个回收列表。 |
| 改动与失败恢复 | 将保留率改为 0.25、发酵热量改为 5000，授权玩家在主基线游戏内重载。真实服务端消费或读数同时显示两项新值，先前取得的快照仍为 0.8/4000。再提交保留率 1.5 及热量 6000，应同时保留 0.25/5000。修正比例后重载，两个新值同时可见。 |
| 解析错误 | 分别试缺键、未知键、重复 TOML 项、坏 TOML、布尔字符串、整数溢出、非有限浮点、列表错元素和未知前缀。记录原因、发布次数不增加、旧对象继续可读。另测 ratio 端点 0、1，真实空名单与有效模板。 |
| 会话与权限 | 服务器打开独立存档 B，读到 B 自己的值。远端普通玩家执行管理员重载应被拒绝，玩家自己配置文件的值不能改变 B 的读数。 |

两版分别编译实际宿主适配。1.21.1 需留同一候选 JAR 的真实专服和游戏客户端运行、管理员重载反馈、前后读数及退出状态。夹具可读取已发布快照作为 P2 消费者，机器的实际产出随各玩法任务复验。G2 另须通过整体构建、双端加载、方块放置/破坏与保存读回、网络 echo 及 common 平台依赖检查。[双版本取证](../platform/verification.md)
