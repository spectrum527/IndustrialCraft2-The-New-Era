# 活跃配置键（A10、B#40、C-MF10）

## §1 清单与默认值的口径

[逐键表](active-keys.tsv)是 P2-T5 的固定声明清单，每行给出区分大小写的完整键、类型、首次启动的默认值、作用域、校验范围和用途。默认值列是 JSON 标量或数组。58 项中含 17 个布尔值、9 个整数、24 个单精度数、6 个双精度数、2 个字符串列表。精确保留 `Stirling`、`Kinetic`、`FluidReactor`、`hU_per_run`、`biomass_per_fertilizier` 等键的既有拼写。

A10 的分母为 2.9.40 随包声明的 91 个固定项，其中 58 项有消费方，33 项按 B#40 去除。另一个按物品动态扩展的世界扫描段和五条资源文件说明均不属于分母。首发对照为 1.19.2 修复正式版 `1.2.0-port.20261119`，JAR SHA-256 `dc1b803b24101d6372f3cbf7ffb633fed21f5339efb16e455e5a4ed5cbe0ccab`。每一项默认均核过包内配置。其中两条 UU 默认使用修正后的物品 ID，回收名单使用正式版实际匹配的物品。

| 项目 | 参考端与重建期望 |
| --- | --- |
| 回收白名单 | 包内明确给出空值，对应零条允许项，使用黑名单。显式空数组是合法默认。 |
| 回收黑名单 | 包内六项在修复正式版依次解析为玻璃板、木棍、雪球、薄雪、雪块和 IC2 木脚手架。表中已给出这六项的现代 ID。新配置直接接受它们。 |
| UU 预定义 | 正式版把历史铱矿、铱碎片标识改为 `ic2:iridium_ore`、`ic2:iridium_shard`，初始相对价值分别 12000、1333，圆石为 1。物品配方仍可影响最终估值。 |

## §2 可执行的值域与作用域

全部 58 项使用重建的 `SERVER` 作用域。专服和集成服的逻辑服务器消费当前存档的配置，远端玩家的本机设置无法更改它。P2 不要求向客户端 GUI 同步整份快照。历史版本在实例配置文件读取这些设置，部分消费方只在启动时读取。按存档装载与热重载属于目标端平台契约。[配置运行规格](runtime.md)

| 表中值域 | 发布前检查 |
| --- | --- |
| `bool` | 原生布尔 true 或 false。 |
| `int32` | 原生整数，范围 −2147483648 到 2147483647。拒绝小数及数值字符串。 |
| `finite32`、`finite64` | 原生数值，按相应 IEEE 754 精度求值并要求结果有限。拒绝无穷、NaN 和数值字符串。没有独立证据的业务最大值不作为读取限制。 |
| `0..1` | 有限双精度比例，0 和 1 均允许。保留率 0.8 表示保留 80%。 |
| `recipe_inputs` | 有序字符串列表，允许空。元素是命名空间物品 ID，或 `Tag:` 后接物品标签 ID，或 `Fluid:` 后接流体 ID。ID 格式为 `[a-z0-9_.-]+:[a-z0-9/._-]+`，不带数量后缀。标签或物品属于哪个注册表在对应消费阶段核对。 |

一般数值在参考配置中没有一套逐键统一的最小或最大值。表列类型界限和有限数检查构成重建的输入域。采矿机随包说明给出 1 至 4 对应四种电池的例子。未据此设置额外整数上限。反应堆爆炸上限小于或等于零时停用相应过热破坏，核电倍率非正时不满足红石启堆条件，两种沼气倍率非正时对应燃料项不启用。这些是由消费者执行的效果。

## §3 留给数据包与后续玩法的行为

1.12.2 的铜、铅、锡、铀矿各有启用、次数、矿脉大小、最低高度、最高高度和分布六项，共 24 项，按 C-MF10 交给世界生成数据包。旧版另有顶层世界生成选项。三个目标的固定配置均不为它们添加键。旧 BuildCraft 燃料集成开关也不登记。

1.12.2 在作物登记时读取禁用清单，随包默认明确为空。2.9.40 和首发修复包均未提供该配置及其消费。因此 P2 本表中的 agriculture 项数为零。新增农业配置须有相应玩法任务与依据。

修复正式版恢复了三处原先没有消费者的设置。P2 的分母按 A10 固定，对应玩法按下表复验。

| 修复版行为 | 下游复验 |
| --- | --- |
| 采矿额外矿物 | 修复专项在同种世界对照，默认留下石头。选入石头并重启后能采走。P7-T4 复验可配置选矿及实际产出，数据入口另据玩法规格确定。 |
| 量子装备的冲刺选择 | 可在通常的疾跑与另一个加速键之间选择，装备任务核对绑定、能耗和移动效果。 |
| 喷气背包加装排除项 | 加装时检查配置列出的装备，装备及配方任务对照可安装与被排除样本。 |

错误输入的回归覆盖未知路径、错类型和非法数值。例如已有配置加入旧世界生成开关或修复版恢复的三键之一，本次候选应被拒绝并保留最近一次有效快照。迁移文档归 P9-T5。[范围决策](../../decisions.md)
