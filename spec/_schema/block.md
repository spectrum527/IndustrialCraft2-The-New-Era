# 方块规格模板

> 以下字段均必填；无此行为写“不适用”；事实、设计示例与待确认项分开，数值附单位。

## 1. 字段说明与必填项
| 字段 | 说明 |
|---|---|
| id / name / evidence | `ic2:` ID、名称、用途、核验版本、静态/实测/设计/待确认状态 |
| properties | 硬度、爆炸抗性（游戏量）、碰撞/外形（方块单位）、工具与掉落条件 |
| state / placement | 合法状态与默认值；朝向、放置条件、邻居要求及旋转失败结果 |
| inputs / interaction | 玩家、工具、红石、邻居变化输入；权限、服务端判定和耗材 |
| outputs / drops | 可见状态、信号、普通破坏/扳手/爆炸/创造模式掉落；数量和内容保存 |
| boundaries / failures | 空手/错误工具、非法朝向、卸载/重载、重复交互；拒绝时哪些状态不变 |
| regressions / dependencies | decisions 修复后行为、原版 bug（回归用例）、量化场景及未交付依赖 |

## 2. 填写规则
输入、输出、边界、失败模式各自写明；关联机器页仍须说明方块行为归属，不能只贴一个 ID。
模型、声音只描述玩家可见/可听需求；资源路径、实现结构不属于本模板。

## 3. 示例（自造，仅展示填写方法）
`ic2:example_block`：1 方块立方碰撞体；硬度 2 游戏量、抗性 10 游戏量；只允许水平朝向，默认北，开关默认“关”。
输入：任意坚实顶面放置；空手右键使状态在“关/开”之间切换；不消耗物品。
输出：开时比较器 15 级，关时 0 级；正确工具普通破坏掉落自身 1 个，爆炸不掉落；无库存。
边界：上/下旋转请求拒绝；卸载后保存开关与朝向。失败模式：错误工具破坏无掉落，不产生额外物品。
parity：放置后右键 2 次，信号依次为 0、15、0 级；两次非法旋转后朝向仍为北，结果精确。
此 ID 与数值不是已注册内容或真实方块默认值；真实方块/机器合例见 [`打粉机`](../machines/macerator.md) §2、§4。
