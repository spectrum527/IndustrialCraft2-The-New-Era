# 物品规格模板

> 以下字段均必填；空能力写“不适用”，未确认内容须说明待确认范围与责任任务。

## 1. 字段说明与必填项
| 字段 | 说明 |
|---|---|
| id / name / evidence | `ia2:` ID、名称、用途、核验版本与静态/实测/设计/待确认状态 |
| stack / durability | 个/堆叠、耐久点；是否可损坏，耗尽时的剩余物 |
| stored_data | 可保存的电量 EU、流体 mB、模式等；默认值、合法范围与转移保留规则 |
| inputs / use | 使用对象、按键/交互、权限、消耗条件、冷却 tick；成功/失败何时扣物品 |
| outputs / effects | 精确产物/余物、世界变化、显示与声音；概率及随机试验方法 |
| boundaries / failures | 空电/满罐/满背包、无效目标、重复请求、存档恢复；不得产生复制或无故吞物 |
| regressions / dependencies | 修复后行为与原版 bug（回归用例）；场景、容差、尚未交付的规格 |

## 2. 填写规则
输入、输出、边界、失败模式单独列清；纯材料也必须明确“无主动使用效果”。
注册项用 `ia2:`；引用外部物品时保留其所属命名空间，不能把外部输入冒充本项目注册项。

## 3. 示例（自造，仅展示填写方法）
`ia2:example_powder`：纯材料，每堆叠最多 64 个；无耐久、无电量、无流体、无额外保存数据。
输入：拾取、丢弃、手动拆分/合并。输出：仅库存数量变化；无主动使用、音效或世界效果。
边界：其余格均满、已有 63 个时拾取 2 个，只能合入 1 个，余下 1 个仍存在于可拾取物中。
失败模式：右键无效目标不扣物；满库存时拾取失败不删除地上物品；重载后数量精确保留。
parity：64 个拆为 32 + 32 个，再合并为 64 个；额外 1 个不能并入，所有数量精确。
此 ID 是设计示例，不能作为配方或注册表的真实条目。
