# 能量规格模板

> 以下字段均必填；EU 为能量，EU/t 为速率，EU/包为单包量，tier 无量纲；三者不可混用。

## 1. 字段说明与必填项
| 字段 | 说明 |
|---|---|
| id / scope / evidence | `ia2:` 场景/设备 ID、适用网络、核验版本及静态/实测/设计/待确认状态 |
| inputs / ports | 供/受能方向、tier、EU/包、包数/t、EU/t 上限（无须明确）、注册/移除时点 |
| storage / demand | 容量 EU、初始 EU、需求/拒收/余量规则、存档与升级缩容处理 |
| transfer / loss | 同步 tick 时序、分配/公平性、损耗 EU/路径、取整与能量守恒式 |
| outputs / config | 实收/扣款/损耗/可见信号；活键、默认值及关闭保护后的行为 |
| boundaries / failures | 零/负/非有限数、断线、环路、过压、过流、区块卸载及失效端点 |
| regressions / parity | 修复后行为、原版 bug（回归用例）；初态、tick 数、各账户量、容差和待交付依赖 |

## 2. 填写规则
每条公式写变量单位、定义域及取整；输入、输出、边界、失败模式缺一不可。
重建行为 = 修复后：主网络采用同步结算，并预留可替换计算行为（decisions.md B#6），不宣称支持真实异步。
原版 bug（回归用例）：请求异步计算会失败；同一合法网络在同步模式连续运行 100 tick，应无计算模式异常、无丢失/重复结算。

## 3. 示例（自造无损测试夹具，非真实导线参数）
`ia2:example_transfer`：源初始 64 EU，每 tick 最多 1 包、32 EU/包；受端容量 32 EU、初始 0 EU；单向、损耗 0 EU。
输入：保持连接运行 2 tick。输出：第 1 tick 源 32 EU、受端 32 EU；第 2 tick 两端不变，总能量 64 EU。
边界：受端满时请求 0 EU；断线后实收 0 EU。失败模式：负数/非有限数输入拒绝，双方储能不变。
parity：逐 tick 精确断言上述能量，正式网络场景容差 ±1%；此夹具无过压与过流分支，真实规则待 P1-T3。
真实机器受能边界见 [`打粉机`](../machines/macerator.md) §2、§6；完整 tier/损耗/拓扑规格尚未交付。
