# GUI 规格模板

> 以下字段均必填；使用统一数据驱动布局，手写例外须单列理由（decisions.md B#8）；仅写交互行为。

## 1. 字段说明与必填项
| 字段 | 说明 |
|---|---|
| id / target / evidence | `ia2:` 界面 ID、关联对象、打开/关闭条件、核验版本与证据状态 |
| geometry | 基准宽高、原点、坐标和尺寸（逻辑 px）；缩放、文字溢出与语言需求 |
| slots | 槽名、数量、坐标/排列、合法物品、玩家输入/输出与快捷转移规则 |
| inputs / actions | 点击、拖放、按键、按钮的允许值、权限、冷却、服务端确认方式 |
| outputs / sync | 展示字段、单位、范围、进度归一化/取整、更新触发、可见/禁用条件 |
| boundaries / failures | 无权限、越界/重复动作、目标卸载、重连、旧状态；拒绝时库存与能量守恒 |
| parity / dependencies | 结构/数值/交互断言，已交付依赖与待确认布局/快捷键 |

## 2. 填写规则
输入、输出、边界、失败模式各自明确；展示不得越权修改机器状态；无槽位/按钮须明示。
坐标是功能需求，真实布局需核验；设计示例不能作为真实机器坐标来源。

## 3. 示例（自造，仅展示填写方法）
`ia2:example_meter`：176 × 166 逻辑 px；左上角为原点；无槽位/按钮，只读展示 0–600 EU。
输入：有查看权限的玩家右键打开，关闭键退出。输出：在 (8, 8) px 显示“储能 / 容量 EU”，储能变化时更新。
边界：0 EU 与 600 EU 均可显示；文字过长允许换行；重连后先取服务端快照。
失败模式：无权限不打开；目标卸载立即关闭；伪造写入请求拒绝，电量不变。
parity：分别提供 0、300、600 EU，显示精确值；只读界面任意点击 10 次后储能仍不变。
真实打粉机的静态核验布局见 [`打粉机`](../machines/macerator.md) §5；快捷转移规则尚待 P1-T7 / P4-T5。
