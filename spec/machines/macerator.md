# 打粉机（ic2:macerator）

## 1. 身份与依据
用途：将可打粉原料转成粉末等产物，连接原料与后续加工链；配方类型 `ic2:macerator`。
默认参数、方块、配方、槽位、升级公式与 GUI 依据 2.9.40 静态核验。M01 和 M08 已在 1.19.2 参考实例采样，实测状态见 §7。负责人依据这两组实测批准了 B#41 的重建目标，实现和回归待执行。
配置：无专用打粉机耗能倍率；`misc/enableEnetExplosions` 默认 true 控制过压爆炸，`protection/wrenchLogging` 默认 true 仅控制拆卸记录；不引入死键。

## 2. 参数、方块与槽位
| 参数 | 默认值 / 单位 / 行为 |
|---|---|
| tier / 受能 | 1（无量纲），32 EU/包；六个世界面均可受能；无独立总 EU/t 输入上限，需求为容量减当前储能 |
| 容量 | 基数 600 EU；加载/重算后为 600 EU + 300 tick × 2 EU/t = 1200 EU，不能把基数作为有效上限 |
| 工作耗能 / 时长 | 默认 2 EU/t、300 tick/次，每批加工 1 次。空闲与断电等待耗能 0 EU/t。连续加工计费见 §3、§6 |
| 方块 | 硬度 2 游戏量、爆炸抗性 10 游戏量；完整 1 方块碰撞体；正确工具才有普通采掘掉落；金属音色 |
| 朝向 / 物品 | 水平四向；放置时正面朝向玩家；扳手可水平旋转；物品最多 64 个/堆叠 |
| 普通 / 扳手掉落 | 正确工具采掘得 `ic2:machine` 1 个；扳手拆卸得 `ic2:macerator` 1 个；储能和进度不写入掉落物，库存另行掉出 |

| 槽位 | 数量 / 容量 | 玩家权限 | 自动化规则 |
|---|---|---|---|
| 输入 | 1 槽，最多 64 个且受物品上限约束 | 放入有配方的物品，可手动取出 | 上方优先插入；其他世界面亦可插入；有效原料不可抽出；失效原料可抽出但受其他输出槽优先级影响 |
| 输出 | 1 槽，最多 64 个且受物品上限约束 | 只取出 | 下方优先抽出；其他面亦可抽出；拒绝插入 |
| 放电 | 1 槽，受物品堆叠上限约束 | 放入兼容电池/可供能物品（含红石），可取出 | 所有面禁止插入/抽出；放电等级跟随机器 tier |
| 升级 | 4 槽，每槽最多 64 个 | 仅接受 §3 类型，可取出 | 所有面禁止插入/抽出 |

## 3. 行为与升级
- 空闲：没有可匹配且数量足够的输入，或完整产物放不下；active=false、进度 0 tick，不耗能。有效配方与输出空间就绪后，至少有本 tick 所需能量才工作。
- 每个成功工作 tick 按 E 扣一次本 tick 的工作能量，增加 1 tick 进度。达到时长时扣原料、提交产物、清零进度，再重新匹配配方和输出空间。下一批首次推进进度时才扣该批的工作能量。
- 断电：储能不足本 tick 需求时不扣电，active=false；若配方仍有效则保留进度，恢复供电后续作。输入消失、数量不足或改为不同配方时丢弃旧进度并重新匹配。
- 卸载/重载保存库存、储能与进度；加载、库存变化触发升级重算；进度按原百分比换算，取 `floor(旧进度/旧时长 × 新时长 + 0.1)` tick。
- 接受超频、变压、储能、普通/高级物品弹出、普通/高级物品拉取；拒绝流体、红石反相与远程接口升级。本机不接受红石启停，外部红石不改变加工。
- 令 n、m、s 分别为超频、变压、储能升级总个数（各槽合计，各 0–256 个，所有升级类型合计不超过 256 个）；基础耗时 d = 300 × 0.7ⁿ tick，批次数 b = min(ceil(1/d), 2147483647) 次，时长 L = max(1, round(d × b)) tick，耗能 E = min(round(2 × 1.6ⁿ), 2147483647) EU/t。
- 非负数 round 为四舍五入；有效 tier = 1 + m；容量 C = min(600 + 10000 × s + L × E, 2147483647) EU。静态原版缩容时不裁剪已有储能；重建的超容量保留/显示待确认（见 §8），不得当作电量保留率配置处理。
- 例：0 个升级得 L=300 tick、E=2 EU/t、C=1200 EU；1 个超频得 L=210 tick、E=3 EU/t、C=1230 EU；1 个储能得 C=11200 EU；1 个变压得 tier 2、128 EU/包。
- 升级在加工判定之后传物；每个弹出/拉取升级堆叠 k 个时，对每个所选相邻库存最多传 4^min(4,k−1) 个/t（k=1 时 1 个/t）；默认面向全部相邻库存，可指定世界面；传输不得复制或丢物；目标剩余空间不足时的数量核验、高级过滤细节待 P1-T4。

## 4. 输入
玩家右键打开 GUI；手动放料、取产物、装卸电池与升级；扳手先尝试旋转，不能旋转且允许拆卸时拆机；非法上/下朝向不生效。
能源来自相邻供电或放电槽；只在有余量时尝试放电，电池按其传输限额供能。红石为 800 EU/个的一次性耗材；静态原版会整份注入而非按余量截断，重建的超容量处理待确认。
自动化面均为世界面，不随机器正面转动；“优先”不是排他限制。输入无配方时拒绝常规插入，不把输入当燃料烧毁。

## 5. 输出
产物见 §7；active 仅在工作时为 true；比较器输出 floor(进度 × 15 / L) 级，完成后回 0 级；GUI 显示储能/容量 EU、归一化进度、槽位与 active。
GUI 基准 176 × 166 逻辑 px，原点左上；输入 (55,16)、输出 (111,30)、放电 (55,52)、升级列起点 (151,7)，玩家背包起点 (7,83) px；能量条 (59,37)、进度条和配方入口 (80,38) px；入口区域 21 × 11 px，仅请求查看配方。
重建行为 = 修复后（decisions.md B#36）：客户端在 active 开始时播放工作循环音，停止/卸载时停止；断电中断播放中断音。专用服连接的客户端亦须正常播放，不依赖服务端音频设备。

## 6. 边界与失败模式
- 输出不足：一轮需要的完整输出放不下则不开始、不扣料不耗能；取走产物后可开始。运行中输出容量变化与配方重载的进度策略尚待 P4 规格，不允许丢物或超堆叠。
- 无效/不足输入：不开始；工作中失去有效配方则进度归零。缺电即使仅差 1 EU 也不推进；空间足够、恰有 E EU 时允许工作 1 tick。
- 默认启用过压保护：实际受入单包超过 32 EU 时触发机器电气爆炸并移除机器；32 EU/包本身不过压；关闭 `misc/enableEnetExplosions` 后不因过压炸机。范围/伤害由尚未交付的能量/爆炸规格决定。
- **重建行为 = 修复后（decisions.md B#41）。** 完成批次时可检查下一批的储能条件，该检查不扣能。默认无升级、无外部供能时，2 个煤和 1200 EU 在 600 tick 产出 2 个煤粉，余能 0 EU。单个煤仍需 300 tick、600 EU。

### 原版 bug（回归用例）
B#41 已实测。M08 在第 300 tick 完成第一批时扣了 4 EU，比该 tick 的工作耗能多 2 EU，第二批因此缺最后一个工作 tick 的能量。§7 保留 M08 的原版状态，M09 检验批准的修复目标。

B#36：专用服机器循环音疑似静音；输入有效原料并持续供能，让连接的客户端经历开始、断电、恢复、卸载，要求工作音存在且停止后无残留循环。原版现象尚未实机复现；重建目标按修复后定义。

## 8. 依赖与未确认范围
模板已交付于 `_schema/`；本页内联方块与代表配方，不依赖虚构的配方文件。全量配方（P1-T5）、通用机器/升级（P1-T4 / P4）、GUI 快捷转移（P1-T7 / P4-T5）、能量与放电耗材的超容规则（P1-T3 / P1-T12）、音频细节（P1-T12 / P8-T4）尚未交付。
阻塞范围：缩容后存量/显示；高级过滤；耗材溢出；输出或数据包运行中变化。高堆叠导致的整型乘加边界亦须核验，上述升级公式暂只约束中间量未溢出的范围。这些需后续 Spec + QA 核验，不授权实现者猜测。B#41 的计费状态机由 P4-T4 实现，P1-T8 承接 M09 回归。目标实现与回归仍待执行。
