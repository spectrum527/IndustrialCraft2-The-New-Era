# Workshop 界面的图稿与实机坐标

每台设备的面板尺寸、原图、原生槽号、背包、按钮、计量区、额外裁片和依据均记录在 `assets/ic2/gui/workshop-layouts.json`，四个目标共用。槽坐标指物品图标的 16×16 左上角，按钮与计量区用 `[x,y,宽,高]` 记录，纹理裁片坐标从原图左上开始。

成形机、洗矿机、离心机、罐装机、热机、流体设备与 UU 设备各自读取完整作者面板。无需单独图稿的设备根据公开 GUI 定义拼接作者的 `common.png`。感应炉还使用作者绘制的输入和输出槽裁片。选择新式高炉画稿时，原料、回收容器、空气柱和双产品槽对齐该画稿的横向布局。

余额、工作进度、热量、样式和罐内容跟随服务器容器数据。原位置的液柱和计量区显示对应状态，面板右外侧信息图标和原位区域提供完整数值与配方名称。没有独立进度图的设备保留画稿留白，用提示展示数值。图稿上的电池或容器占位中，现有设备支持的槽与实机控制在布局中列出。洗矿机的两个盛水容器槽、工作位、退桶和罐液量均可直接操作。电热发生器与电力动能发生器使用相应的十格部件区，读取旧存档时也计入槽内原有的部件堆叠。

洗矿机闲置时也可由水容器预充。界面显示当前罐量、排队容器和已返还的容器结果。[设备流体输入规格](../machines/washing-and-geothermal.md)

Forge 原生界面检查通过活动玩家右击打开窗口，记录屏幕原点、窗口宽高、GUI 缩放、原生槽坐标及截图。像素对比使用实际画面与回交图稿，在物品、当前读数和按钮覆盖之外比对原始 RGB 值。在 Forge 分支可准备实机客户端后运行下列命令。像素验收的 Python 环境需提供 Pillow。

```shell
./gradlew :forge:1.19.2:prepareQaPlay
python3 src/forge/1.19.2/qa/authored_screens.py --output /path/to/workshop-ui
```
