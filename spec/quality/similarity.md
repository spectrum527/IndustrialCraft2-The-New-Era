# 双基线相似度门禁（A23、A26）

## §1 输入与原判断

检查 `--candidate` 下的全部 Java 文件，对 2.9.40 和 2.8.222 各传一次 `--reference`。逐文件计算两版比较中的最高 5-gram Jaccard 分数，并记录连续 8 行命中。
原判断为分数 >25% 失败、>15% 且 ≤25% 警告、≤15% 通过。任一连续 8 行相同直接失败。

## §2 原样骨架例外

使用 `--boilerplate-policy <文件>` 显式选择清单。省略此参数时采用原判断。CI 固定使用仅含三个批准条目的[仓库清单](../../tools/similarity/boilerplate.json)，新增或修改条目须负责人审批。
清单是 JSON 对象，键为相对 `--candidate` 根的规范 POSIX 路径，值为 64 位小写十六进制 SHA-256。拒绝重复键、绝对路径、反斜杠、驱动器前缀，以及空、`.` 或 `..` 路径分量。清单可保留当前候选树中未出现的合法路径。
按候选相对路径查清单。以一次读取的原始文件字节计算 SHA-256，并用同一份字节做相似度比较。路径与哈希均匹配时，豁免由分数产生的警告或失败。任一不匹配或路径未列入清单时采用原判断。
连续 8 行命中始终失败。显式选择的清单不可读或无效时返回 `error`（退出码 2），即使当前缺少参考输入。

## §3 报告与回归

选择清单时，逐文件保留原始分数、原判断和连续 8 行命中，并明确报告清单是否匹配、是否应用例外和最终状态。门禁按最终状态汇总，存在失败时退出码为 1，只有通过或警告时为 0。

| 回归输入 | 预期结果 |
| --- | --- |
| 已列路径与原始字节均匹配，分数触发警告或失败，连续 8 行检查通过 | 保留原分数与原判断，应用例外，最终通过 |
| 原路径的内容改变一个字节（包括换行） | 哈希不匹配，采用原判断 |
| 原始字节移至未批准路径 | 路径不匹配，采用原判断 |
| 未列入清单的候选文件 | 采用原判断 |
| 省略 `--boilerplate-policy` | 采用原判断 |
| 清单不存在、无法解析、哈希格式错误、路径非法或重复 | 返回 `error`，退出码 2 |
| 路径及哈希均匹配，且有连续 8 行命中 | 报告匹配和例外未应用，最终失败，退出码 1 |
