# 能量网络行为规格

## 1. 范围、证据与单位
依据能量模板 §1–§3、打粉机样板 §2/§6；适用服务端、同一世界内的能量传输。设备端口与储能行为见 [设备规格](devices.md)。
证据：参考版本 2.9.40 的生效行为及修订资料已静态核验；参考实例未运行，本文没有实测值。自造夹具只解释公式，不新增注册内容；不表示 P0/G0/G1 通过。
EU 是能量，EU/包是一次逻辑包的预算，包/轮是每次结算的预算，EU/t 是世界 tick 的速率；tier 为无量纲整数。没有另设安培、电压或每根线的独立总电流上限。
表内 EU/t 上限只适用于已稳定拓扑、每 tick 一轮的区间；拓扑变更时的额外结算见 §3、N-B1。

## 2. 输入：等级、供给与需求
源输入为 tier t、可供能 O（EU）、该轮包预算 p（包，按每轮计数）；受端输入为需求 D（EU）与可受能面。合法端口须位于同一世界的相邻方块，出面与对方入面同时允许才能连接。
普通源 p=1；多包源须声明正整数 p。O≤0、p≤0 或源 t<0 时本轮不供能；负 tier 记诊断，不将其变成 tier 0。NaN 供给不能成为活跃源；无限供给会先受有限包预算截断，不能笼统拒绝所有无限供给夹具。
对整数 0≤t<30，名义包量 P(t)=8×4ᵗ EU/包；t≥30 的静态上限为 2⁶³ EU/包。负 t 不在该式定义域。常见设备使用 t=1–5，不因列高等级数值而批准新内容。

| tier t（无量纲） | P(t)（EU/包） |
|---|---:|
| 0 / 1 / 2 | 8 / 32 / 128 |
| 3 / 4 / 5 | 512 / 2048 / 8192 |
| 13 / 14 | 536870912 / 2147483648 |
| 29 / ≥30 | 2305843009213693952 / 9223372036854775808 |

数学反算为 ceil(log(q/8)/log(4))，q>0 EU；静态参考在 q≤0 时返回 0。该反算不是“合法源 tier”的定义：例如 q=1 EU 得 −1，精确幂附近亦有浮点边界疑点；重建的极小量/异常数处理留 N-B6，不自行钳制或修复。
单轮源预算 M=min(O,p×P(t)) EU；普通源最多使用 M，一份预算可以沿多条路径拆分，并非只能供一个受端。多包源每个逻辑包预算不超过 P(t)，至多尝试 p 包，无成功传输时停止后续包。
算例：tier 1、O=100 EU、p=1，M=32 EU；p=4 时 M=100 EU，而非强制输出 128 EU。边界：O=0 或 p=0 时 M=0 EU；t=1 的等级边界是 32 EU/包，33 EU 属于更高包量区间。
稳定拓扑下，对一个源统计 n≥1 个 tick，实际平均输出速率 R源=ΣK/(n tick) EU/t；对一个受端为 R收=Σq/(n tick) EU/t。单源上限为 pP(t)/1 tick；例如100 tick源扣3200 EU为32 EU/t，1 tick源扣11 EU而实收10 EU则分别为11和10 EU/t，不能将二者混写。
D 为本轮收集时的正需求快照；内置受端未关闭接收且 S<C 时报告 D=C−S EU，否则 0 EU。没有独立总 EU/t 输入上限；多源或多包重复部分填充的超容问题见 N-B2，不把快照误称为逐次更新的剩余量。

## 3. 同步结算、连接与断线
**重建行为 = 修复后（decisions.md B#6）**：能量结算以同步为主；允许将计算行为替换，但本范围不提供真实异步模式，也不得落入不可用的异步失败分支。
稳定拓扑的参考时序是方块本 tick 处理后、世界 tick 末传能；刚完成拓扑变更时，tick 首还可触发结算。不得照搬“所有传输恒在 tick 首”的早期概括；变更期间每 tick 的轮数及新架构承诺留 N-B1。
连接添加/移除排队处理；已经排队添加但尚未生效时移除，会取消该添加；已登记端点移除时先禁用端点，再处理拓扑变更。区块卸载移除能量端点，重载需重新登记。
源或受端被禁用后不再向其结算；中间导线的移除、转向、重着色及卸载至路径失效的精确延迟尚待 N-B1 采样，不承诺“点击当 tick 即断”或固定 1 tick 延迟。
输入算例：拓扑已经确认无连通路径，源初始 64 EU、无其他输入/支出，保持断线 100 tick；输出为受端增量 0 EU、源仍 64 EU。边界：再连接后先确认拓扑就绪，再开始计时，不能把等待期算成稳定速率。
同色线的电气匹配可静态确认；异色端口须按双方电气兼容性判断，不能以外观连线为导通证据。默认黑色与染色线的外观/电气判定差异留 N-B5；不得自行把黑色定义成通配色。
路径在拓扑变化时重建；每源对每受端保留一条候选路径。源数≤2048 时按累计损耗优先，更多源的路径不保证最小损耗；不许把任意规模网络都写成“全局最优”。
多个源的处理起点会随机化；多条受端路径在部分 tick 会改变处理起点，没有固定等分或长期公平性保证。并发供需不足场景只断言总量与限额，不捏造逐受端固定份额。

## 4. 路径损耗与取整
令每节点内阻 r 以 EU/成功路径传输为单位：源、受端各 0.002 EU，导线取下表 ℓ；相邻两节点连接损耗为 (r₁+r₂)/2 EU。
原始路径损耗 Lraw 为沿途连接损耗之和；由 N≥1 段同材质线组成的简单路径，Lraw=N×ℓ+0.002 EU；无导线的直接相邻源/受端为 0.002 EU。绝缘层数不改变 ℓ。
`misc/roundEnetLoss` 默认 true：L=floor(Lraw) EU，向下取整一次，不逐线取整；false：L=Lraw EU，不取整。静态参考在配置读取时固定该选择；重新建网不等于重新读取配置，热重载承诺待 P2-T5。

| 导线类型 | ℓ（EU/段） | 名义额定（EU/包） |
|---|---:|---:|
| 锡 / 铜 | 0.2 / 0.2 | 32 / 128 |
| 金 / 铁 | 0.4 / 0.8 | 512 / 2048 |
| 玻璃纤维 | 0.025 | 8192 |
| 侦测 / 分离 | 0.5 / 0.5 | 8192 / 8192 |

算例：1、5、10 段铜线的 Lraw 分别为 0.202、1.002、2.002 EU，默认 L 分别为 0、1、2 EU；100 段玻璃纤维 Lraw=2.502 EU，默认 L=2 EU。
边界：默认 4 段铜线损耗 0 EU，5 段为 1 EU；关闭取整后，直接相邻仍损耗 0.002 EU。没有“绝缘越多线损越大”的本版行为。
一次路径尝试剩余源预算为 m EU。若 m≤L，受端禁用或没有正需求，实收与源扣款均为 0 EU。
否则拟送达 a=min(m−L,D) EU；受端拒收 r EU，正常定义域为 0≤r≤a。实收 q=a−r EU；q>0 时源扣 K=q+L EU；全拒收时源不扣线损。正常账户满足源扣款=受端实收+线损。
有任意拒收时，该受端本轮不再尝试；没有拒收且本次 a≥快照 D 时也停止向该端尝试。部分成功且 a<D 时快照不递减的后续风险见 N-B2。
算例：m=32 EU、L=1 EU、D≥31 EU、r=0 EU，q=31 EU、K=32 EU；若 D=10 EU，则 q=10 EU、K=11 EU；若 r=a，则 q=K=0 EU。各量不再取整。
边界：m=L 时完全不传；m=L+0.5 EU、D足够时实收 0.5 EU。异常拒收值、负损耗、非有限需求留 N-B6，不假定扩展端点会正确处理。

## 5. 输出、边界与失败模式
每轮可观察源实际扣能、受端实收、路径损耗、包数预算、最大传导量以及断线/过载结果。统计中的送达量不能冒充含线损的源扣款；GUI 不得把 EU/包标成独立 EU/t 总输入上限。
以下副作用均为静态参考行为；重建只采用已闭合范围，N-B3/N-B4 中的异常组合不授权直接实现或自动修复。
- 无损成功路径、需求足够且受端无特殊保护时：受入包量超过 P(受端tier) 会触发设备电气爆炸；恰等于 P 不因该条件爆炸。默认电气爆炸强度参数为 2.5 游戏量，不能当作半径或最终伤害；完整爆炸规则待 P1-T12。
- 导线判定量取路径本轮最大的 K（含线损），不是所有包的 EU 总和。导体静态移除条件为 K>名义额定+1 EU，比较严格大于；例如锡线 K=33 EU 未达到该移除条件，34 EU 才达到，不能将额定 32 与比较阈值 33 混写。
- 绝缘剥除阈值为 K>9001 EU，且同段导体未被优先移除时才剥一层；不能假定“超额定必先剥绝缘”。
- 触电吸收阈值：锡线绝缘 0/1 层为 8/32 EU；铜为 32/128 EU；金为 32/128/512 EU；铁为 32/128/512/2048 EU；不可加绝缘的三种线为 2147483647 EU。
- 触电候选需与导线附近 3×3×3 方块范围相交；每路径取所遇最大 floor(K−吸收阈值) EU，跨路径累加为 H EU，伤害 ceil(H/64) 点。例：一条裸铜路径 K=128 EU，H=96 EU，伤害 2 点；最终实体伤害抗性另属 P1-T12。
- `misc/enableEnetCableMeltdown` 与 `misc/enableEnetExplosions` 默认均 true。静态参考前者 false 会跳过整批线缆、电击、设备爆炸副作用；后者 false 仅禁止设备爆炸。是否保留这种联动留 N-B3，不按键名自行拆分。
- 有损路径可能以 q 入队、再以 K 判受端过压，导体过载亦可牵连受端；这些混合分支留 N-B4。普通“超过 32 EU/包”的打粉机边界不得推广成任意有损/保护组合的完整判定。

## 6. 原版 bug（回归用例）
B#6：参考能量结算本来走同步；强行进入未完成的异步路径会失败。重建行为为 §3 的同步模式，不保留可选择但必然失败的假模式。要求用同一合法夹具连续 100 tick，记录结算轮数、能量账、诊断及无计算模式异常；真实异步可选模式数必须为0，不得以旧失败入口作为后备结算；不要求复现异常原文。
以下场景均待 QA 执行，无已存在脚本或真实期望值文件；正式能量容差 ±1%，整数阈值/拒收/断线为精确断言。N01–N06 是量化要求，不是通过记录；N07–N10 只采样，不设通过结论。

| 场景 | 输入、操作与可量化输出 |
|---|---|
| N01 等级/包预算 | 自造无损端点 tier 1，O=100 EU、p=1、D≥32 EU，一轮源扣/受端收均 32 EU；p=0 两者均 0 EU |
| N02 损耗/守恒 | 5 段铜线，m=32 EU，D≥31 EU，一轮源扣 32 EU、收 31 EU、损耗 1 EU；m=1 EU 时两账户均不变 |
| N03 部分/拒收 | 同 N02，D=10 EU 得源扣 11 EU、收 10 EU；全部拒收时源扣 0 EU；每轮记录实收+损耗=源扣 |
| N04 同步修复 | 自造无损夹具，源 3200 EU、tier 1、单包，受端空余≥3200 EU；稳定拓扑 100 tick 收/扣各 3200 EU，无异步计算异常；真实异步可选模式数为0，未进入旧失败分支 |
| N05 断线 | 唯一通路已确认断开，源 64 EU、受端空，保持 100 tick；源仍 64 EU、受端增量 0 EU |
| N06 导线阈值 | 只取一轮、受端 tier 2、锡线、足够需求，分别令 K=33/34 EU，记录前者不按导体移除条件移除、后者移除；源需为较高 tier 夹具 |
| N07 调度采样 | 稳定网络中插线/断线/旋转/卸载，每次前后各记录 3 tick，并区分 tick 首/末的轮数及所有账户变化，等待 N-B1 |
| N08 容量采样 | 同一导线网、每路默认取整后L=0 EU，两个单包源各 32 EU，受端 C=40000 EU、S=39950 EU，关闭受端输出及物品充放电；单轮静态推导可能收 64 EU 至 40014 EU，仅作复现线索，等待 N-B2 |
| N09 保护采样 | 1段铜线、默认取整L=0 EU，向空闲打粉机送 64 EU/包，分别组合两个保护开关；记录副作用。再改变线损和绝缘，记录 q/K 与受端结果，等待 N-B3/N-B4 |
| N10 色线采样 | 自造源320 EU、tier1、单包，受端余量≥320 EU且无其他支路；相同两段线分别红/红、红/蓝、黑/红，稳定后各记录10 tick外观连线与实收EU，等待 N-B5 |

## 7. 阻塞分支与下游
下列“静态参考现象”不等于已批准重建行为或已确认 bug；只阻塞相应分支，其余已核验参数可评审。需要 Spec/QA 核验与负责人取舍，不由实现者猜测。

| 编号 | 尚未闭合的分支 / 交接 |
|---|---|
| N-B1 | 拓扑变更后可能 tick 首额外结算；断导线的失效延迟、稳定恢复时点、区块边界时序。QA 记录 N07 后再定调度承诺 |
| N-B2 | 同轮多源或多包的需求快照不递减、受端不钳制，可能超过容量；不得擅自限流或复制该异常作目标，先做 N08 与多包变体 |
| N-B3 | 两个保护开关的联动范围；不得擅自分拆，先做 N09 |
| N-B4 | 有损路径的入队/过压量不一、导体过载牵连、特殊过载保护、实际爆炸/电击结果；先做 N09，再衔接 P1-T12 |
| N-B5 | 颜色外观与电气兼容性差异；不把黑色通配作为已批准行为 |
| N-B6 | 极小/超大能量反算、幂边界误差、非法扩展端点、非有限数及溢出范围；需数值契约，不自行修复 |
