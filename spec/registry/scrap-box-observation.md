# 废料盒的开启

同一组 64 台朝上的发射器各装三组 64 个废料盒，通过真实红石脉冲执行 128 次。单独运行 Forge 1.19.2 修复基线 1.2.4 的交付包。两个抽查发射器各剩 64 个，产物区的实体总计 8,192 个未开启的 `ic2:scrap_box`。本次黑箱只覆盖发射器行为，未测该修复基线的手持开启。

本发行恢复旧版公开说明中的玩法。生存手持右键和每次发射器脉冲各消耗一个盒子，从同一个原生可重载战利品池抽取一件物品。依据 [Industrial-Craft-Wiki 的 1.71 权重表](https://wiki.industrial-craft.net/index.php/Scrap_Box)，以整数保存同样的相对权重。旧名称映射为目前注册的橡木告示牌、满锡罐、植物球和对应矿物。四个平台共享同一份数据。
