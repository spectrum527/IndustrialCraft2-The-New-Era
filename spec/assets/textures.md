# 机器、物品与线缆的纹理

## §1 路径与交付范围

以 2.9.40 Experimental 的注册 ID、模型引用和图集中的资源 ID 为起点。1.12.2 独有路径随已选玩法补入。一个内容条目可用多张图，多个模型也可以共用一张图。规格和新图按路径交接，登记每项的关联内容、状态和最终包内路径。

| 类别 | 需要一起核对的画面 |
|---|---|
| 机器 | 正背、顶底、侧面、朝向、开停状态、工作指示、共享机壳，发电机、储电、变压与充电设备。方块的背包模型需一起预览。与机器绑定的 GUI 背景、仪表和动态覆盖层随对应界面核对并重绘。 |
| 物品 | 材料、零件、电池、工具、装甲及升级件。检查物品栏、手持、掉落、装备穿戴层和由模型选择的充电、模式、损耗或动画状态。方块物品可能直接借用方块的面。 |
| 线缆 | 裸线、绝缘等级、材料、可染颜色、玻璃纤维、探测与分流线缆的活动状态。检查线芯、端头、分支、泡沫覆盖、手持图和六向连接。各几何组合可共用纹理。 |

全新画布绘制各张图，记录作者和可追溯的创作来源。参考图用于核对功能和像素尺寸。保持像素比例、透明边缘、UV 分区与动画帧序。原版路径中的 `blocks/`、`items/` 也属于资源键。模型、图集、物品定义或装备层在不同目标版本需要不同声明时，由 Client 在对应模块绑定，记录两端的资源路径。第三方覆盖包应仍能命中既有资源键。

## §2 批次

1. 首批样张为发电机和打粉机的停机/工作面与共用外壳、BatBox 的输出面、裸铜缆和绝缘铜缆的世界及手持图、充电电池各档。逐张核对朝向、可读性和透明度。
2. 扩至章程的 39 项 MVP，覆盖橡胶、锡矿、基础材料与装备、四台加工机器和其余一级线缆。对仅借用游戏模型的橡胶树叶创建 IC2 自有纹理，世界与物品模型共用。共享外壳只计一次。
3. P6/P7 按内容波次扩充至全部机器、物品和线缆。对动态渲染、着色、实体、装备与库存没有独立 PNG 的条目逐项核对。新增内容在注册时同时登记资源槽位。已剔除或挂起的条目单列处置及依据；保留在游戏内的状态均需覆盖。

两类运输管各 8 种和两档泵盖进入 G5 物流切片。逐种核验物品与放置模型、转角、方向、管口、装拆/连接与覆盖；新图在八条首发产线中复查，无私有原图依赖。

## §3 批次验收

- 逐项对照注册表、模型、图集、动画侧车及来源表。每个投产路径关联新作、作者、许可和日期；在无私有目录的三个目标生产 JAR 中检查实际文件。相同源文件哈希可以发现直接拷贝，原创来源还须核对创作记录。
- 在 1.21.1 客户端冷启动并重载资源，实际检查批次的背包、手持、放置六向与工作态；线缆至少检查端点、直线、拐角、T 形、交叉/六向、染色和适用的泡沫或活动状态。检查缺图方格、UV 错位、透色、动画与日志。以一个覆盖包替换已知旧键，记录游戏确实显示替换图。26.1.2 与 26.2 分别从 P6 同做运行验收。
- 每批记录分母（本批需交付的唯一路径和无独立图的内容）、登记数、包内命中数、实机通过数及截图。放行条件为本批适用项全部有处置、投产纹理全部为新作、缺失纹理与断链引用为零。公开前按 A7/A22 另核对模型、GUI、音效等其余生产资源。
